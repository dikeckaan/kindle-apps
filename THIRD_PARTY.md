| Turkish news RSS/Atom feeds (AA, TRT Haber, Hürriyet, Sözcü, NTV, CNN Türk, BBC Türkçe, Cumhuriyet, Milliyet, Sabah, Habertürk, DW Türkçe, Euronews, Yeni Şafak, BirGün, Karar, Star, Akşam, Dünya, Bloomberg HT) | publishers' public feeds; only the feed text and the article link are shown, no images | Gazete |

| Tarifler online recipe library (`https://kaandikec.com/kindle-apps/tarif/v1/`: `index.tsv` + `s/NNNN.txt` shards, ~3,600 recipes: every Vikikitap `Yemek:` recipe, English Wikibooks `Category:Recipes`, German Wikibooks `Kochbuch/` recipes) | CC BY-SA 4.0 (Wikibooks contributors); each shard lists page, revision and authors of its recipes, the app shows address, revision and licence under every recipe; `LICENSE.txt` next to the index | built from the MediaWiki API by `tools/tarif/build-shards.py` in the release workflow (not in git) | Tarifler (index cached in `data/tarif/lib/`, opened shards kept up to 5 MB) |
| TheMealDB API (themealdb.com) — optional, only with a key the user enters | free test key "1" for development/educational use only, public apps need a supporter key; data credited to TheMealDB | Tarifler |
